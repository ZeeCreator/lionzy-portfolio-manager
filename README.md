## Perintah Penjalanan 

```sh
# Step 1: Gunakan Git Untuk Menarik Project Ini
git clone <YOUR_GIT_URL>

# Step 2: Arahkan ke direktori proyek.
cd <YOUR_PROJECT_NAME>

# Step 3: Instal dependensi yang diperlukan.
npm i

# Step 4: Untuk Menjalankan Dalam Developer Ketik
npm run dev
```
